# Code of conduct

Kapto follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/):
everyone taking part, in issues, pull requests, reviews and anywhere else
the project is discussed, is expected to be welcoming, considerate and
respectful, and to treat others' work and time with care.

Harassment, insults, personal or political attacks, and publishing others'
private information aren't accepted, whoever does them.

## Reporting

Report behaviour that breaks this code to the maintainer at
carlos.rzdr@gmail.com. Every report is read, kept confidential, and answered.
The maintainer may remove comments, commits or other contributions that
break it, and may ban someone from the project, temporarily or for good.
