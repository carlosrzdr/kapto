# Guides

Step-by-step instructions for specific tasks, such as connecting a robot or
setting up uploads. Guides are added as the features they describe are built.

| Guide | For |
|---|---|
| [Control recording from your own programs](control-recording.md) | Starting, stopping and watching episodes from a robot program or script through the API, with curl, Python and Rust |
| [Check a robot package against your robot](check-a-package.md) | Linting a package, and decoding a capture of the robot's traffic with it before recording |
| [Try uploads on this machine](try-uploads.md) | Starting S3-compatible storage with Docker, pointing the demo at it, and watching episodes go up, without a cloud account |
| [Record a ROS 2 robot](record-a-ros2-robot.md) | Declaring a robot's ROS 2 topics in a package, running Kapto on the robot's ROS 2 network, and reading the recordings back with ROS 2's tools |
