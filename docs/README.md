# Kapto documentation

Kapto is an edge collector for robot data: it receives data from robots,
records it reliably, shows it live on the robot's 3D model, decides what is
worth keeping, and uploads it to storage you own.

Kapto is in early development. These pages describe what exists today and
grow with the code.
